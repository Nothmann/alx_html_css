This project is part of the ALX Software Engineering curriculum, focusing on foundational HTML and CSS skills. It builds on the previous My_First_Portfolio project and introduces layout techniques, responsive design, and basic styling.

 Key Concepts Covered
Flexbox Layouts

Vertical and horizontal positioning using display: flex

Proportional sizing with flex: 2 and flex: 1

Scrollable content areas with overflow-y: auto

Responsive Design

Mobile-friendly layout using the <meta viewport> tag

Adaptive styling via .works_on_smartphone class

Custom Styling

Enhanced visuals with background colors, borders, and shadows

Semantic HTML structure with <header>, <main>, <article>, <aside>, and <footer>

 How to Run
Open index.html or tweets.html in any modern browser. Resize the window to test responsiveness. All styles are loaded from base.css and styles.css.
